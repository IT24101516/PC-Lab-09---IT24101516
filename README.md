# SE3082 – CUDA Lab 09

**Student ID:** IT24101516  
**Module:** SE3082 – Parallel Computing

This lab introduces CUDA programming using an NVIDIA GPU in Google Colab.

## Lab Exercises

1. CUDA environment setup
2. Adding two numbers using CUDA
3. Vector addition using 512 blocks
4. Vector addition using 512 threads
5. Vector multiplication (10 million elements)
6. Element-wise matrix multiplication (10,000 × 10,000)

## How to Run

1. Open the `.ipynb` notebook in Google Colab.
2. Enable the T4 GPU runtime.
3. Run the cells in order.

The notebook contains the CUDA programs, outputs, and exercise answers.
